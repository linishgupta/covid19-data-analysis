# COVID-19 Global Data Analysis Dashboard

## 📌 Project Overview
Analyzed global COVID-19 data (Jan 2020 onwards) covering 180+ countries to identify case trends, death rates, and recovery patterns using Google Sheets.

## 🛠️ Tools Used
- Google Sheets
- Pivot Tables
- Data Cleaning (handling blanks, duplicates)
- Charts (Bar Chart, Line Chart)
- Dashboard with KPI Cards

## 📊 Key Insights
- The US recorded the highest confirmed cases (42.9 lakh) among the top 10 countries, followed by Brazil and India
- Global cases showed exponential growth starting April 2020
- Global death rate stood at ~3.97% as of the latest recorded data
- Total confirmed cases: 1.64 crore+ | Total deaths: 6.54 lakh+ | Total recovered: 94.6 lakh+
