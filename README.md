# COVID-19 Data Analysis & Dashboard

## 📌 Project Overview

This project analyzes COVID-19 data to understand the global impact of the pandemic across different countries and over time.

The project was created using **Google Sheets** and includes data cleaning, pivot table analysis, data visualization, trend analysis, and dashboard creation.

## 🛠️ Tools & Skills Used

- Google Sheets
- Data Cleaning
- Pivot Tables
- Data Analysis
- Data Visualization
- Charts
- Dashboard Creation
- Basic Statistical Analysis

## 📊 Dataset

The dataset contains country-wise and date-wise COVID-19 statistics, including:

- Confirmed Cases
- Deaths
- Recovered Cases
- Active Cases
- New Cases
- New Deaths
- New Recoveries
- Deaths per 100 Cases
- Recovered per 100 Cases
- Deaths per 100 Recovered
- Number of Countries

## 🔎 Analysis Performed

The project includes:

- Country-wise COVID-19 analysis
- Top 10 countries by confirmed cases
- Comparison of confirmed, death, and recovered cases
- Date-wise confirmed case trend analysis
- Global death rate calculation
- Pivot table analysis
- Data visualization using charts
- Dashboard development

## 📈 Dashboard

The dashboard provides a quick overview of:

- Total Confirmed Cases
- Total Deaths
- Total Recovered Cases
- Global Death Rate
- Top 10 Countries by COVID-19 cases
- Confirmed Cases over Time

## 💡 Key Insights

- The United States recorded the highest confirmed cases among the countries shown in the analysis.
- Brazil and India were also among the countries with the highest confirmed cases.
- The number of confirmed cases increased significantly over the analyzed period.
- The comparison of confirmed, recovered, and death cases highlights substantial differences in COVID-19 outcomes across countries.
- The dashboard provides a consolidated view of the major COVID-19 indicators.
